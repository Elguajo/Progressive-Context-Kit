# Tooling Bootstrap

Use `prompts/SETUP_TOOLING.md`. Preferred brands are Semble, Serena, RTK, Superpowers, gstack, Context7, and conditional GitHub Spec Kit. Installed does not mean loaded or invoked. Verify current official setup before installation; ask once before user/global configuration; persist status so later sessions do not re-ask unnecessarily.
