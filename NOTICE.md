# Notice

Progressive Context Spec Kit is a new independent iteration inspired by
`Elguajo/Token-Efficient-Spec-Kit` (MIT). The original repository is not modified by this
package.

v1.6.0 provides separate user-level global adapters for Codex and Claude Code, one vendor-neutral repository context/workflow router, progressive Skills/protocols, branded preferred-tool routing, and atomic inherited/framework contracts. It keeps the v1.4 runtime model while clarifying the token-efficient Spec-Driven rationale. The archived previous Custom Instructions are retained unchanged only as migration/evaluation evidence.

Human onboarding lives under `docs/human/` in the source distribution and is deliberately excluded from Project Runtime installs.
