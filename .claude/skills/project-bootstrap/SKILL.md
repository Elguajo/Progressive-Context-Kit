# Project Bootstrap

Use `prompts/START_NEW_PROJECT.md`. Create compact canonical project state, choose architecture pragmatically, create only necessary phases with exactly one current marker, select/tool-bootstrap a justified tooling profile, and begin implementation unless a user-only blocker exists. For an existing product repository, use `existing-project-adoption` instead.
